📌 Proje Genel Yol Haritası
Aşama 0 (Sistem & Ortam Hazırlığı): KVM/Libvirt sanallaştırma katmanının, gerekli sistem paketlerinin ve Terraform Libvirt provider bağımlılıklarının yerel Linux makinesine kurulumu ve doğrulanması.
Aşama 1 (Terraform & Cloud-Init ile Altyapı): HCL modülleri, Ubuntu Cloud Image, Cloud-Init (ISO) entegrasyonu ve 3 adet VM'in (1 Master, 2 Worker) statik IP ve SSH erişimiyle ayağa kaldırılması.
Aşama 2 (Ansible ile İşletim Sistemi Yapılandırması): Swap alanlarının kapatılması, kernel modülleri (overlay, br_netfilter), IP forwarding ve containerd runtime kurulumu.
Aşama 3 (Kubernetes Bootstrapping): Master düğümde kubeadm init çalıştırılması, join token elde edilerek Worker düğümlerin kümeye dahil edilmesi.
Aşama 4 (Pod Networking & Cluster Verification): CNI (Calico) eklentisinin uygulanması, düğümlerin ve sistem pod'larının Ready durumunun doğrulanması.

**Aşama 0 (Sistem & Ortam Hazırlığı)
1.Donanım Sanallaştırma Desteğini Doğrulama:
egrep -c '(vmx|svm)' /proc/cpuinfo
****Eğer VirtualBox kullanıyorsanız:
Sanal makinenizi tamamen kapatın. VirtualBox ana penceresinde makinenin Ayarlar (Settings) > Sistem (System) > İşlemci (Processor) sekmesine gidin ve "Enable Nested VT-x/AMD-V" (İç İçe VT-x/AMD-V Etkinleştir) kutucuğunu işaretleyin.
2.KVM, QEMU ve Libvirt Paketlerini Yükleme:
sudo apt update
sudo apt install -y qemu-kvm libvirt-daemon-system libvirt-clients bridge-utils virtinst ebtables dnsmasq-base genisoimage git curl
3.Sudo-less Libvirt Yetkilendirmesi:
sudo usermod -aG libvirt $USER
sudo usermod -aG kvm $USER
newgrp libvirt
4.Libvirt Daemon'ını Başlatma ve Hypervisor Kontrolü:
sudo systemctl enable --now libvirtd
virsh nodeinfo
